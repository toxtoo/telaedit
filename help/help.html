1. Getting started

TelaEdit is a text editor for writing web pages by hand. It colours HTML, CSS and JavaScript, helps you insert common tags, checks your page with HTML Tidy, checks your spelling, and opens your page in your browsers with one click.

When you start TelaEdit it reopens the files you had open last time, puts your cursor back where it was, and restores the window size and position. If nothing was open, it starts a new page from your default template.

Formerly SiteForge. TelaEdit was called SiteForge before version 0.5. The first time you start TelaEdit it copies your settings from the old ~/.config/SiteForge folder, which is left as it was.
Some features need extra programs. HTML Tidy needs the tidy program, and spell checking needs aspell or hunspell. See Checking your HTML with Tidy and Spell checking for how to install them.

2. The TelaEdit window

Menu bar

The menus are File, Edit, Search, View, Insert, Tools, Browsers, Settings and Help. Each is described in the sections below.

Toolbar

Under the menu bar is a toolbar with tabs. Click a tab to see its buttons; point at a button to see its name.

TabWhat is on it
StandardShow/hide Explorer, New, Open, Save, Close All, Undo, Redo
HTMLParagraph, Heading 1, Heading 2, Link, Image, Horizontal Rule
FormattingBold, Italic, Underline, and the four indent / unindent buttons
ListsUnordered List, Ordered List
ToolsButtons for your own external tools
BrowsersOne button for each browser you have set up

Editor tabs

Every open file has its own tab. You can drag tabs to reorder them. A file with unsaved changes shows a * before its name and the tab text turns red. The window title shows the full path of the file you are working on.

Explorer panel

On the left is the Explorer panel with two tabs, Explorer (your folders and files) and Snippets. Click the small left arrow at the top of the panel to hide it, and the small right arrow at the left edge of the window to bring it back. View > Explorer does the same. See The Explorer.

Output / Messages panel

At the bottom is a panel that appears when TelaEdit has something to tell you, such as the report from HTML Tidy. Close it with the × button in its top-right corner. It reappears next time there is a message.

Status bar

The bar at the very bottom shows short messages such as “File saved”, and on the right it always shows the cursor position as Line and Column.

Opening a file from the Explorer

Double-click a file in the Explorer panel to open it. If it is already open, TelaEdit simply switches to its tab.

What TelaEdit remembers

When you quit, TelaEdit remembers which files were open, where your cursor was in each, which tab was active, your bookmarks, the window size and position, the Explorer width, and how the Explorer is divided between folders and files. All of it comes back next time.

Untitled pages that were never saved are not remembered. Save a page before you quit if you want to keep it.

Syntax colouring

TelaEdit colours a file according to its ending: .html .htm .xhtml .xml .svg as HTML, .css as CSS, and .js .mjs as JavaScript. Other files, such as .txt, are shown as plain text.

4. Editing

Cut, copy and paste

The usual keys work (Ctrl+X, Ctrl+C, Ctrl+V), and so do the same commands on the right-click menu.

Undo and Redo

Edit > Undo (Ctrl+Z) and Redo (Ctrl+Y).

Indenting

New lines automatically start at the same indent as the line above. The Edit menu also has:

  • Indent Line (Ctrl+]) and Unindent Line (Ctrl+[): move the line the cursor is on.
  • Indent Block (Ctrl+Shift+]) and Unindent Block (Ctrl+Shift+[): move every line in the selected text. Undo reverses the whole block in one step.

Whether TelaEdit indents with spaces or tabs, and how wide an indent is, is set in Settings > Indentation Settings.

Find and Replace

Search > Find and Replace... (Ctrl+F) opens a small window. Type what to look for in Find what and, if you want, a replacement in Replace with. It shows how many matches there are in the current file. Searching ignores upper and lower case.

ButtonWhat it does
Find NextJumps to the next match. Also Search > Find Next (F3).
Find PreviousJumps to the previous match. Also Search > Find Previous (Shift+F3).
Replace NextReplaces the current match and moves to the next one.
Replace AllReplaces every match in the file. Undo reverses all of it in one step in each file.
CloseCloses the window.

Search > Replace... (Ctrl+H) opens the same window with the cursor in the Replace with box. If you select some text first, it is put into Find what for you.

Searching all open documents

Tick Search all open documents in the Find and Replace window to search every open tab instead of just the current one. Find Next and Find Previous carry on into the next (or previous) tab when they reach the end of a file. Replace All asks you to confirm first, replaces in every open document, and then tells you how many replacements it made in each. Each file can be undone separately.

Go to Line

Search > Go to Line... (Ctrl+G) asks for a line number and takes you there.

Word wrap and font

  • View > Word wrap wraps long lines at the window edge instead of running off to the right. It applies to all tabs and is remembered.
  • View > Editor font... lets you pick the font and size for the editor. It applies to every tab and is remembered.

Bookmarks

To mark a line, click in the narrow strip just beside the line numbers. A marker appears. Click it again to remove it. Bookmarks are saved with your session and come back when you reopen the file.

Bracket highlighting

Put the cursor next to a bracket, ( ), [ ] or { }, and it and its partner are highlighted in green. A bracket with no partner is highlighted in red, which helps you spot a missing one.

Tag-pair highlighting

Put the cursor anywhere inside an opening tag such as <div class="box"> and TelaEdit highlights both that tag and its matching closing tag </div>, and the other way round. It copes with tags nested inside each other, and ignores tags that have no partner, such as <br> and <img>. The highlight is hidden while you have text selected.

Change the colour in Tools > Tag-pair highlight colour....

Current line highlight

The line the cursor is on has a pale background. Change the colour in Tools > Current-line highlight colour....

Tag completion

When this is switched on and you type the > at the end of an opening tag, TelaEdit adds the closing tag for you and leaves the cursor between the two. Type <div> and you get <div></div> with the cursor in the middle.

It does not add anything for tags that never have a closing tag: area, base, br, col, embed, hr, img, input, link, meta, param, source, track, wbr.

Switch it on or off with Settings > Tag completion. The choice is remembered.

Word suggestions as you type

While you type, a small list of words already in your document may pop up. Press Enter or Tab to accept a word, or just keep typing to ignore it.

5. Inserting HTML

The Insert menu, and the HTML, Formatting and Lists tabs on the toolbar, put common tags into your page. If you have some text selected, the tags go around it. If nothing is selected, the tags are inserted with the cursor placed between them, ready to type.

CommandInserts
Paragraph<p></p>
Heading 1 / Heading 2<h1></h1> / <h2></h2>
Bold, Italic, Underline<b>, <i>, <u> pairs
Division (div)<div></div>
Unordered List / Ordered ListA <ul> or <ol> with list items. If you select several lines first, each line becomes a list item.
Horizontal Rule<hr>
Link...See below.
Image...See below.

Link...

A small window asks for the address. Type a web address, or click Browse... to pick a file on your computer. TelaEdit works out the correct relative path from your page to that file. Select some text before you start and it becomes the link text.

To work out relative paths TelaEdit needs to know where your page lives, so save the page first.

Image...

Type an image address or click Browse.... A preview and the image size in pixels appear. Fill in the Alternative text (a description for people who cannot see the image) and click OK. TelaEdit inserts an <img> tag with the correct width and height filled in automatically.

6. The Explorer and drag and drop

Moving around

The Explorer tab has two panels, one above the other:

  • The upper panel is a tree of your folders. Click a folder to choose it, and click the small arrow beside a folder (or double-click it) to open or close it.
  • The lower panel lists the files in the folder you chose. Double-click a file to open it in the editor.

Drag the divider between the two panels up or down to give more room to the folders or to the files. TelaEdit remembers where you left it. Above the folder tree, the ↑ Up button goes to the parent folder, and the line under it shows the full path of the folder you are in. TelaEdit also remembers the last folder you used, and the Explorer follows the file you are working on.

Open in file manager

Right-click in either panel and choose Open in file manager to open that folder in your computer's own file manager (Thunar, Nemo, Dolphin and so on), for copying, moving or deleting files. Right-click a file for Open and Open folder in file manager.

Dragging a file into your page

You can drag a file from the Explorer and drop it into the editor. TelaEdit writes the correct relative path for you, at the point where you drop it.

You dropIntoTelaEdit inserts
An image (jpg, jpeg, png, gif, webp, svg, avif, bmp)An HTML page<img src="..." width="..." height="..." alt="">, with the real width and height
Any other fileAn HTML pageA link, <a href="...">filename</a>
A CSS fileA CSS file@import url("...");
Any other fileA CSS fileurl("...")
Drag and drop only works in saved .html .htm .xhtml and .css files, because the path depends on where your file is. If the page has not been saved, TelaEdit asks you to save it first.

7. Snippets

A snippet is a piece of text you use often, such as a navigation menu or a block of boilerplate. Snippets live on the Snippets tab of the left-hand panel, grouped under headings called branches.

Using a snippet

Double-click a snippet in the list. It is inserted at the cursor. If you have text selected, the snippet is wrapped around it: its Before text goes before the selection and its After text goes after.

Managing snippets

Click Manage Snippets... at the top of the Snippets tab. The window lists your snippets and has these buttons:

  • Add – create a new snippet.
  • Edit – change the selected snippet.
  • Delete – remove the selected snippet (after asking).
  • Insert – insert the selected snippet into the current page and close the window.
  • Close

A snippet has these boxes: Branch / Category (the heading it appears under; leave it empty to use “General”), Name, Shortcut, Before text and After text. For a snippet that is just a block of text, put it all in Before text and leave After text empty.

The Shortcut box is saved with the snippet, but it does not yet trigger anything. Use the list on the Snippets tab to insert snippets.

8. Checking your HTML with Tidy

HTML Tidy is a free program that checks HTML for mistakes. TelaEdit runs it on the page you are editing, even if you have not saved the latest changes.

Installing Tidy

Open a terminal and run:

sudo apt install tidy

Running it

Choose Tools > Run HTML Tidy, or click the Run HTML Tidy button in the Output panel. You can also give it a keyboard shortcut in Settings > Keyboard Shortcuts (it is under “Other commands”). The report appears in the Output panel at the bottom. If Tidy finds nothing wrong, you get a message saying so.

Jumping to a problem

Tidy reports each problem on a line like line 12 column 5 - Warning: .... Click that line in the Output panel and the cursor jumps straight to that line and column in your page. (Selecting text in the Output panel to copy it does not trigger the jump.)

9. Document Weight

Tools > Document Weight tells you how heavy your page is, which affects how fast it loads. It adds up:

  • the HTML file itself,
  • local images used by <img> tags,
  • local stylesheets (<link rel="stylesheet">),
  • local scripts (<script src="...">).

It shows each size in KiB, the total in KiB and MB, and how many files of each kind were counted, were missing, or were left out because they are on another website.

The page must be saved, with no unsaved changes, so that the sizes match the file on disk. Images that are only referenced from inside a CSS file are not counted.

10. Previewing in browsers

The Browsers menu opens your saved page in a web browser so you can see the real result. You can have up to ten browsers in the list. The same list appears as buttons on the Browsers tab of the toolbar.

  • The first three browsers in the list have shortcuts: Ctrl+F2, Ctrl+F3 and Ctrl+F4.
  • F12 (Open in Default Browser) opens the page in whichever browser you have marked as the default.
  • The page must be saved first. If it is not, TelaEdit reminds you.

Configure browsers...

Choose Browsers > Configure browsers... to open a table with ten rows. For each browser:

  • Browser name – the name shown in the menu.
  • Executable path – where the program is, for example /usr/bin/firefox. Use Browse... to find it.
  • Icon – choose one of the five generic browser icons from the drop-down list. To use your browser's own icon instead, choose Other icon... at the bottom of the list and pick an image file (PNG, JPG, ICO or SVG). TelaEdit keeps a copy, and the icon then appears in the list for every row.
  • Default – click the round button on the row you want F12 to use.

Click Save when you are finished. Rows left empty are ignored. Until you set your own list, TelaEdit starts with Firefox, Brave and Firefox 4 (an older Firefox in /opt/firefox-4).

11. External tools (GIMP and friends)

You can add your own programs, such as GIMP, to the Tools menu and start them from TelaEdit.

Adding a program

  1. Choose Tools > Configure external tools... (at the bottom of the Tools menu).
  2. On an empty row, click Browse... and choose the program. GIMP is usually /usr/bin/gimp. The Name in menu box fills in automatically, and you can change it.
  3. Click Save.

The program now appears in the Tools menu, below Run HTML Tidy, and as a button on the Tools tab of the toolbar. Click it to start the program. The program runs on its own, so it stays open even if you close TelaEdit.

Options

  • Room for ten programs.
  • Arguments. You can type options after the program, for example gimp --no-splash.
  • Open current file. Tick this box on a row to give the program the file you are editing when it starts. That suits another text editor or a validator, but not GIMP. The file must be saved.
  • To remove a program, clear its row (delete the text in the Program box) and Save.

If TelaEdit cannot find a program, it shows a message with the path it tried.

12. Spell checking

TelaEdit underlines misspelled words with a red wavy line as you write.

Installing a spell checker

Spell checking uses the free aspell or hunspell programs. In a terminal, run one of:

sudo apt install aspell aspell-en

sudo apt install hunspell hunspell-en-gb

If neither is installed, TelaEdit tells you when you switch spell checking on.

What gets checked

  • Only the text a visitor reads. Tags and their attributes, comments, <script> and <style> blocks, and entities such as &nbsp; are skipped.
  • Single letters, words in CAPITALS (such as HTML) and words that contain numbers (such as 4GRID) are skipped.
  • Only HTML and text files (.html .htm .xhtml .txt .md and untitled pages) are checked. CSS and JavaScript files are not.
  • The check runs a moment after you stop typing.

Fixing a word

Right-click a word with a red underline. At the top of the menu you get:

  • Suggested spellings, in bold. Click one to replace the word.
  • Ignore “word” – stops underlining that word until you quit TelaEdit.
  • Add “word” to dictionary – remembers the word for ever. Good for names such as place names.

Below those are the usual Undo, Redo, Cut, Copy, Paste and Select All.

Settings

  • Settings > Spell checking switches spell checking on or off.
  • Settings > Spelling underline thickness... sets how thick the red wavy line is, from 1 (thin) to 6 (very thick). The default is 2.
  • Settings > Spelling language... asks for a dictionary code. The default is en_GB (British English). Use en_US for American English, and so on. The dictionary for that language must be installed.

Words you add are kept in user_dictionary.txt in the TelaEdit settings folder, one word per line. You can edit that file in TelaEdit to remove a word you added by mistake. Restart TelaEdit afterwards.

13. Templates

A template is an HTML file used as the starting point for new pages.

  • File > New starts a page from your default template.
  • File > New from Template... lets you choose any template for this one page.
  • File > Save as Template... saves the page you are editing as a template, in the templates folder.
  • Settings > Default Template... chooses which template New uses.

The first time you run TelaEdit it creates a template called HTML5 Standard: a full HTML5 page with the usual <meta> tags, favicon links and a stylesheet link. You can use it as it is, or set up your own.

Changing the syntax colours

Choose Settings > Syntax highlighting colours..., pick a language at the top, and the table lists each kind of element (tags, attributes, comments, strings and so on). Click an element's colour button to choose a new colour, and tick Bold to show it in bold. The changes apply to your open files straight away and are remembered. Reset this language to the default colours puts that language back as it was.

Changing keyboard shortcuts

The Keyboard Shortcuts window lists every command in three groups: Insert commands, Standard shortcuts and Other commands. To change one, click in its Shortcut box and press the keys you want. Click Save to apply the changes.

  • If you give two commands the same keys, TelaEdit warns you and does not save until you fix it.
  • Restore Defaults puts all the keys back as they were.

16. Where TelaEdit keeps its settings

Everything is in one folder in your home folder: ~/.config/TelaEdit/ (.config is a hidden folder; press Ctrl+H in your file manager to show hidden folders).

ItemWhat it holds
state.jsonOpen files, cursor positions, bookmarks, window size, font, colours, indentation, word wrap, and the tag completion and spell checking settings
shortcuts.jsonYour keyboard shortcuts
browsers.jsonYour browser list
external_tools.jsonYour external tools
browser_icons/Icons you added with Other icon... in Configure browsers
user_dictionary.txtWords you added to the spelling dictionary
templates/Your templates
snippets/snippets.jsonYour snippets

Backing up

File > Backup Configuration... packs the whole folder into a single ZIP file with the date and time in its name. Keep a copy somewhere safe, and you can restore your set-up on another computer by unpacking the ZIP into ~/.config/TelaEdit/ while TelaEdit is closed.

Starting from scratch

To reset TelaEdit to its original settings, close it, then rename the folder ~/.config/TelaEdit to something else (for example TelaEdit-old). TelaEdit creates a fresh one next time it starts.
